# anime-bot

Телеграм-бот, который отдаёт серии из канала-хранилища: поиск по названию,
выбор сезона → серии → озвучки, подписка за Telegram Stars, админка.

Описаний и обложек пока нет — задача этой версии только выдавать видео.

## Установка одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/zfd430792-coder/Vpn-/claude/traffic-consuming-bot-iuxyrf/install.sh | sudo bash
```

Спросит четыре вещи: токен бота от [@BotFather](https://t.me/BotFather), твой
Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)), `API_ID` и
`API_HASH` с [my.telegram.org](https://my.telegram.org) → API development tools.
Дальше сам поставит пакеты, заведёт venv, залогинит юзербота (пришлёт код в
Telegram — введи его), **создаст канал-хранилище**, выдаст боту права админа в
нём и поднимет systemd-сервис.

Вопросы читаются из `/dev/tty`, так что `curl | bash` не ломается. Если не
хочется отвечать руками — передай переменными:

```bash
curl -fsSL <url>/install.sh | sudo BOT_TOKEN=... ADMINS=... API_ID=... API_HASH=... bash
```

## Как это работает

Хранилище — сам Telegram, у себя ничего не лежит. Заливаешь серию один раз,
дальше бот отдаёт её через `copy_message`: файл не перезаливается, трафик
сервера не тратится, **ограничения по размеру нет** — даже для файла на 4 ГБ.

```
   админ                канал-хранилище              юзер
     │                        │                       │
     │  видео + подпись       │                       │
     ├───────────────────────>│                       │
     │                        │   бот читает пост,    │
     │                        │   пишет в SQLite      │
     │                        │   (message_id)        │
     │                        │                       │
     │                        │   copy_message        │
     │                        ├──────────────────────>│
```

Зачем нужен юзербот, если есть бот:

| | Загрузить | Скачать |
|---|---|---|
| Bot API | 50 МБ | 20 МБ |
| Юзербот (аккаунт) | 2 ГБ | 4 ГБ |
| Юзербот + Premium | 4 ГБ | 4 ГБ |
| `copy_message` по готовому посту | **без лимита** | — |

То есть **юзербот заливает, бот отдаёт**. Юзербот же создаёт канал и служит
запасным путём выдачи, если у бота не вышло.

## Как добавлять серии

**Способ 1 — залить в канал-хранилище с подписью.** Бот там админ, увидит пост
сам. Понимает любой из форматов:

```
Тайтл Альфа
Сезон: 1
Серия: 7
Озвучка: Studio Band
```
```
Тайтл Альфа | 1 | 7 | AniLibria
Тайтл Альфа S01E07 [Studio Band]
Тайтл Альфа - 7 серия (AniLibria)
```

Поправил подпись — бот перечитает. Не разобрал — напишет админу, что именно не
понял.

**Способ 2 — прислать видео боту в личку.** С подписью — заведёт сразу; без
подписи — спросит название, сезон, серию и озвучку по шагам. Бот сам скопирует
файл в канал.

**Способ 3 — файл уже на диске сервера:**

```
/pull /srv/video/alpha_s01e07.mkv | Тайтл Альфа | 1 | 7 | Studio Band
```

Заливает юзербот, поэтому проходят файлы до 2 ГБ (4 ГБ с Premium).

## Что видит пользователь

`/start` → меню: 🔍 Поиск · 📚 Каталог · 🔥 Популярное · 👤 Профиль · ⭐ Подписка.

Можно просто написать название — найдёт по совпадению, переживает опечатки
(нечёткое сравнение). Если совпадение одно, сразу открывает карточку.

Дальше **сезон → серия → озвучка**. Если сезон один — сразу список серий; если
озвучка одна — сразу выдаёт видео, без лишнего шага. В плеере: ⏮/⏭ по сериям
(озвучка сохраняется), 🎚 смена озвучки, 📋 все серии.

## Подписка за звёзды

Четыре тарифа: неделя 50 ⭐, месяц 150 ⭐, 3 месяца 350 ⭐, навсегда 1000 ⭐.
Цены меняются в админке. Оплата — Telegram Stars (`XTR`), карт и провайдеров не
надо.

Первые `FREE_EPISODES` серий (по умолчанию 3) бесплатны. Уже открытая серия
повторно квоту не тратит. Возврат звёзд: `/refund <ID>`.

## Админка

Кнопка ⚙️ в меню или `/admin`:

- 📊 статистика: тайтлы, серии, юзеры (и за сутки), подписки, баны, просмотры, заработок в звёздах
- 🎬 тайтлы: переименование, удаление вместе с сериями
- 📣 рассылка всем (с паузами, чтобы не влететь в лимиты)
- ⭐ выдать/снять подписку: `ID дни`
- 🚫 бан/разбан: `ID`, разбан `ID +`
- 💰 платежи и возвраты
- ⚙️ настройки: бесплатные серии, защита от пересылки, автоудаление выданного, цены тарифов

Команды: `/admin`, `/stats`, `/pull`, `/refund`.

## Настройки

`/etc/anime-bot/env` (права 600, внутри токены):

| Переменная | Что делает |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMINS` | ID админов через запятую |
| `API_ID`, `API_HASH` | с my.telegram.org, для юзербота |
| `SESSION`, `STORAGE_CHANNEL` | заполняет `python -m anibot.setup` |
| `FREE_EPISODES` | сколько серий бесплатно (0 — всё платно) |
| `PROTECT_CONTENT` | запрет пересылки и сохранения выданного видео |
| `AUTODELETE` | удалять выданное видео через N минут (0 — не удалять) |
| `DELIVERY` | `bot` или `userbot` — кто отдаёт видео |

Настройки из таблицы (кроме токенов) после первого запуска живут в базе и
меняются из админки.

## Эксплуатация

```bash
journalctl -u anime-bot -f        # логи
systemctl restart anime-bot       # рестарт
python -m anibot.setup            # перелогинить юзербота / создать канал заново
```

## Тесты

```bash
bash tests/run.sh
```

Сеть подменена, токены не нужны. Покрыто: разбор подписей во всех форматах,
каталог и переходы, нечёткий поиск, квота и пейволл, счёт в звёздах и выдача
подписки после оплаты, админка и отказ обычному юзеру, бан, обе схемы заливки,
лимит 64 байта на `callback_data`, совпадение подписей всех 58 хендлеров с тем,
что прокидывает мидлварь.

## Что стоит знать

- **`file_id` привязан к боту.** Сменишь бота — старые ссылки не сработают.
  Поэтому в базе хранится `message_id` поста в канале, а не `file_id`: так
  каталог переживает смену бота, пока жив канал.
- **Не удаляй сообщения в канале-хранилище** — на них ссылается вся база.
- Бот должен остаться админом канала, иначе `copy_message` перестанет работать.
- Ответственность за то, что залито в канал, — на владельце бота.

## Структура

```
anibot/
  __main__.py      запуск бота
  setup.py         интерактивная настройка: логин юзербота + создание канала
  config.py        конфиг из окружения
  db.py            SQLite: каталог, юзеры, подписки, платежи
  parser.py        разбор подписей к видео
  search.py        нормализация названий и нечёткий поиск
  keyboards.py     инлайн-клавиатуры, фабрики callback-данных
  texts.py         все тексты сообщений
  service.py       проверка доступа и выдача серии
  userbot.py       Telethon: канал, заливка, запасная выдача
  middlewares.py   зависимости, регистрация юзера, баны
  handlers/        старт, каталог, плеер, подписка, админка, приём из канала
tests/             проверки без сети
install.sh         установка одной командой
```
